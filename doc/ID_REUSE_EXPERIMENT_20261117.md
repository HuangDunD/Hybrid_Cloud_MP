# YCSB / SmallBank：近期 ID 复用

业务生成访问对象，页面布局决定对象访问能带来多少页面复用。本轮将 YCSB 的页面窗口替换为记录 ID 窗口，并给 SmallBank 加入同一套账户 ID 窗口；不改变事务业务、锁、快照读、提交协议或 MIX 决策。实验执行时，服务器使用未提交工作区文件同步部署；本次提交收录实现与实验记录。

## 参数与生成规则

两个 workload JSON 均在各自负载配置中使用：

```json
"id_reuse_prob": 0.0,
"id_reuse_window_size": 64
```

- 每个 worker 独立持有固定容量的不同 ID LRU，读写共用。YCSB 中是记录 key；SmallBank 中是账户 ID，同一账户关联的 Savings/Checking 仍按原业务访问，不为两张表独立选账户。
- 先保留原生成逻辑中的目标归属选择，再按概率从符合该归属与当前事务去重约束的旧窗口中均匀选 ID；没有候选时回退原 Zipf 生成器。
- 归属判断使用现有固定分区元数据，不查看当前页面持有节点或缓存状态，也不从被选记录扩展采样其同页邻居。SmallBank 以原调用指定的表判断账户归属；没有重新解释原来各事务的表选择。
- 窗口在当前事务目标全部生成之前不变，之后按目标顺序更新。已有 ID 移到 MRU，新 ID 插入，容量满则淘汰 LRU。事务后续是否提交不影响已经完成的窗口更新。
- SmallBank 双账户事务在复用候选中排除第一个账户；原采样器的不同账户检查仍保留。YCSB 固定写归属模式保留原来的事务内 key 去重，未额外修改其他模式的重复 key 语义。
- 复用选择有 worker 种子派生的独立随机流；概率 0 不消耗该流，也不维护窗口，保留原 Zipf/归属随机数调用。开启复用后，基础 Zipf 流只在回退时推进；不声称各概率生成相同事务序列。
- 本轮接入 Zipf 路径；开启复用需要 `use_zipfian=1` 和正窗口容量。关闭时原来的非 Zipf 路径仍可用。TPC-C、SmallBank 的历史长事务入口不加入这次改动。

概率不是实际 ID 重访率或页面命中率：基础采样也可能重访，复用分支也可能回退。概率 1 在候选充足时可能长期维持相同小集合，不保证热点定期轮换。不同 worker 的窗口可能重叠，复用还可能改变记录冲突。

## 代码入口

- `workload/id_reuse.h`：两个负载共用的 `IdReuseWindow::Select/Remember`，仅保存 ID 与独立随机状态。
- `compute_server/worker/worker.cc`：分别在 `RunYCSB`、`RunSmallBank` 创建 worker 私有窗口，跨事务保留。
- `compute_server/worker/handler.cc`：读取统一参数；默认关闭，窗口 64 个 ID。
- `workload/ycsb/ycsb_db.h::generate_ten_keys`：在原目标归属选择之后采样 ID，十个目标全部确定后更新窗口。
- `workload/smallbank/smallbank_db.h::get_account`：账户采样；`smallbank_txn.cc` 的六个常规事务在账户目标全部确定后更新窗口，再执行原业务。

## 验证方法

所有编译和运行在服务器完成，本地不编译、不跑模拟测试，不增加仓库测试脚本。基线 HEAD `09fed8e` 加未提交工作区变更，结果以 source fingerprint 区分实际源码。

先对两个负载分别进行默认关闭、概率 1 / 窗口 1 的 Lazy/Cornus 各 5 秒短测，检查默认配置读取、候选不足、去重回退和实际事务完成。

正式对照：三个计算节点，每节点 8 worker，RDMA，θ=0.6，NO_WAIT，日志开启，现有 `-O0 -DDEBUG` 构建。窗口 64 个 ID，概率 0/0.5/0.9，每点 30 秒，Lazy 与 Cornus，两轮反转负载、概率和模式顺序，共 24 次正式执行。没有追求系统峰值，也不调整刷盘、缓存或协议参数。

- YCSB：每事务 4 读 6 写，固定三个写归属，与之前页面实验的固定归属方案一致。保留的 `local_ratio=0.5` 在固定写归属模式下不控制目标放置。
- SmallBank：写事务比例 0.6、`local_ratio=0.5`，保留原事务类型与目标选择。没有移植 YCSB 的固定三写归属；必须同时查看只读/单写/多写路径比例，不能跨负载直接比较 TPS 或假设提交工作量相同。

64 个 ID 不等于先前的 64 页；本轮各概率之间做内部对照，旧页面结果仅作为不同生成机制的历史观察。

分析复用已有统计：Lazy 的 `local_manager + owner_manager + forwarded_page + wait_release` 为跨节点相关逻辑获页过程，单列存储取页与权限升级；Cornus 用成功/冲突回复合计的 remote fetch RPC。双方计数不是同一种网络报文，尤其不能将 Cornus 的远程记录访问叫作整页传输。按完成尝试（含回滚）归一化，同时报告回滚率、执行/提交时间和 Commit TPS。若回滚上升，不能把提前终止导致的访问减少解释为复用收益。

## 结果

四台服务器增量编译通过；8 次真实集群功能短测、24 次正式执行均完成。72 份正式有效配置核对通过，无统计 WARNING、完成尝试覆盖差异或运行失败。正式 YCSB 的 Lazy 写者均为 1、Cornus 均为 3；SmallBank 保留原只读与写者分布。功能短测验证了实际执行、断言和统计对账，不等于完整业务不变量或故障恢复审计。

测试源码指纹：`98e9670c2242047c400af2cfc9a05e5672b9513cb57fd177d0f8c174b82bdbf3`。四台部署的七个变更源码文件与本地快照哈希一致。结束后开发源码 JSON 恢复默认关闭、窗口 64（YCSB `write_owner_count=0`），四台服务器均无残留实验服务。

### 远程获取与吞吐

以下次数按两轮累计完成尝试归一化。TPS 是两轮观测范围，不是置信区间；节点窗口 TPS 求和沿用原报告口径。Lazy 使用上述四条跨节点相关获页路径，Cornus 是远程记录 RPC，不能解释成对等的网络报文数。

| 负载 | ID 复用概率 | Lazy 获页/尝试 | Cornus fetch/尝试 | Lazy Commit TPS | Cornus Commit TPS |
|---|---|---|---|---|---|
| ycsb | 0 | 5.982 | 6.619 | 5841–7342 | 6497–6971 |
| ycsb | 0.5 | 3.440 | 6.622 | 7968–8597 | 6336–6855 |
| ycsb | 0.9 | 1.133 | 6.624 | 8862–9855 | 6070–6637 |
| smallbank | 0 | 1.093 | 0.934 | 22245–22430 | 23645–24424 |
| smallbank | 0.5 | 0.698 | 0.878 | 22026–22812 | 23899–24406 |
| smallbank | 0.9 | 0.265 | 0.797 | 22496–23222 | 22303–23249 |

**YCSB：** 概率 0→0.9，Lazy 跨节点相关取页约减少 81%，Cornus 的 RPC 数量基本不变。概率 0.5 时两轮 Lazy 分别领先 25.4%、25.8%；0.9 时分别领先 48.5%、46.0%。高复用的相对收益在反向执行顺序下重复出现。概率 0 时第一轮 Lazy 领先 5.3%，第二轮落后 10.1%，没有稳定基线胜者。

**SmallBank：** Lazy 的取页约减少 76%，高复用时也明显少于 Cornus。但概率 0.9 的两轮吞吐分别领先 4.1%、落后 3.2%，两者区间重叠；不能声称 Lazy 稳定更快。概率 0 和 0.5 时均是 Cornus 更快。

两轮绝对性能有波动：YCSB 无复用 Lazy 的提交时间从 1.553 增至 2.280 ms/尝试，同期存储平均 fdatasync 从 0.787 增至 1.109 ms，执行时间仅从 1.583 增至 1.666 ms。这说明绝对 TPS 受当时的持久化等待影响；本轮没有定位该波动的根因，不能据此断言云端限流。保留全部数据，不删除较慢基线或仅挑有利一轮。

### 执行与提交时间

单位为 ms/完成尝试，包含回滚；阶段均按累计时间归一化。

| 负载 | 概率 | Lazy 执行 | Lazy 提交 | Cornus 执行 | Cornus 提交 |
|---|---|---|---|---|---|
| ycsb | 0 | 1.620 | 1.875 | 0.847 | 2.516 |
| ycsb | 0.5 | 1.034 | 1.651 | 0.834 | 2.519 |
| ycsb | 0.9 | 0.569 | 1.760 | 0.808 | 2.624 |
| smallbank | 0 | 0.205 | 0.861 | 0.113 | 0.878 |
| smallbank | 0.5 | 0.143 | 0.906 | 0.105 | 0.869 |
| smallbank | 0.9 | 0.073 | 0.952 | 0.095 | 0.933 |

SmallBank 高复用下，Lazy 的执行由 0.205 降至 0.073 ms，约减少 64%；提交却从 0.861 增至 0.952 ms。完整尝试平均耗时从 1.073 降至 1.049 ms，净收益很小。Cornus 高复用的完整尝试为 1.053 ms，双方接近。这个负载支持“复用可降低执行代价”，但没有证明它一定带来吞吐领先。

单次 Lazy 获页并未更快：YCSB 从约 0.199 增至 0.351 ms/次，SmallBank 从约 0.153 增至 0.175 ms/次；收益主要来自次数减少。剩余调用的路径构成、竞争和等待可能变化，不能假设每次未命中都有固定代价。

窗口采样与维护的开销计入完整事务时间和 TPS。`total - begin - execute - commit - abort` 的未归属时间，YCSB 从约 0.015–0.017 增至 0.163–0.166 ms/尝试，SmallBank 从约 0.004 增至 0.020–0.021 ms/尝试；其中还包括其他负载准备工作，不是独立的窗口计时，不应重复加入总时间。

### 需要一起解释的变化

- YCSB 的 Lazy 回滚率为 1.45%–2.17%，Cornus 为 2.90%–3.19%；SmallBank 各点约 0.01%–0.02%。Lazy 获取次数的大幅下降没有伴随更高的回滚率，不能用更多提前回滚解释，但分母仍明确是完成尝试。
- YCSB 全阶段存储取数据页也减少：Lazy 约 1.040→0.136 次/尝试，Cornus 约 0.572→0.168；淘汰约 1.017→0.032 与 0.428→0.016 次/尝试。复用同时影响页面驻留，不能将全部执行收益只归给计算节点间搬页。
- SmallBank 存储取数据页约 0.018–0.019 次/尝试，各点未观察到淘汰；其取页变化没有同时出现类似 YCSB 的大幅存储缺页下降。统计包含初始阶段，30 秒无淘汰不等于长期稳态证明。
- SmallBank 的 Cornus 远程记录访问也约减少 15%。业务会跨 Savings/Checking 表访问同一账户，窗口筛选保留原单次采样的归属约束，但不保证关联表的最终参与者分布固定。其只读/写者比例见下表，不能套用 YCSB 的固定三写解释。

| SmallBank 复用概率 | 0 写者 % | 1 写者 % | 2 写者 % | 3 写者 % |
|---|---|---|---|---|
| 0 | 40.03 | 41.27 | 16.04 | 2.66 |
| 0.5 | 40.03 | 41.56 | 15.97 | 2.44 |
| 0.9 | 40.03 | 42.35 | 15.60 | 2.02 |

上述写者比例以已有 writer 路径计数之和归一化；不是所有发起尝试的比例。Lazy 各点约 40% 只读、60% 单写。

## 对混合代价模型的意义

将生成粒度改为业务 ID 后，两个负载仍能自然产生页面复用，Lazy 都可以减少跨节点相关获页；YCSB 还出现了稳定的高复用吞吐优势。SmallBank 则给出另一条边界：当原本执行开销很小、提交等待占主要部分时，即使取页减少很多，整体吞吐也可能只接近远程执行。

因此决策需要比较“预计节省多少执行时间”与“最终提交路径及其他开销”，而不能仅用复用概率或远程次数作阈值。此处只验证动机和边界，没有新增 MIX 策略，没有外推为任意窗口大小、负载或长期运行下的结论。Cornus 是本轮使用的 2PC 家族对照；未新增普通 2PC 的性能对照。
