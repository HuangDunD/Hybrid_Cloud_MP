## 三、遗留缺陷 D-1（唯一 FAIL 项，如实记录）

**现象**（`runs/r2c-20260923-c5-anchor-early-001`）：恢复本身 1 秒完成（Phase 3 COMPLETE、103 页、目录 affected=0），但之后 table 0 page 32 的 X 取页连环 stuck：在途 fetch 等死节点 grant 满 45.5s 才放弃（`remote grant stalled past deadline`，lazy.cc:751）；随后每个重试事务再 stuck 45s 被强制解锁（`stuck local latch force-released (X) stolen_remote_mode=2`，5 分钟 3 次＋1 次 L16-Forfeit），驱动 wall budget 耗尽、终局不全。

**定性**：故障边界在途 X-fetch 的 grant/latch 残留未彻底清理＋stall 检测不识别"对端已 failed"（仍等满 45s）。早锚点（冷缓存，事务必走远程取页）才必然触发；global 模式因恢复窗口全拒、无并发 fetch 而不触发；锚点 12/40（热缓存）未触发。

**修复方向（下一轮）**：① stall 检测发现对端在 failed_nodes_ 时立即放弃不等 45s；② stall-abort 路径补全本地 latch/远程 grant 释放；③ 清理覆盖"恢复清理之后新产生又中止的在途 fetch 残留"。属 29.1 清单外的新层缺陷，须按 29.2 纪律先复现样本再改。
